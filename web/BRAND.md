# IACTS Technocollege CME 2026 — Brand Contract

## Central idea

**The Living Operative Field** — the authored cardiothoracic model remains present like a specimen in an operating field while the conference unfolds around it; scroll moves it from exact anatomy through controlled disassembly and back to a textured whole.

## Intended feeling

Precise optimism: clinically credible, technologically progressive, and unmistakably human.

## Visual system

- **Field:** surgical white `#FFFDFC`
- **Primary incision:** IACTS red `#B3122A`
- **Signal red:** `#E32646`
- **Deep tissue:** `#5F0717`
- **Ink:** `#160A0D`
- **Pale tissue wash:** `#F8E9ED`
- Red is the only interface accent. The anatomical model keeps its authored UV texture colours and authored normals without tinting, recolouring, or blend-mode alteration.
- Hairline grids, registration marks, numbered specimens, and asymmetric editorial columns replace generic cards.

## Type and voice

- Heavy sans serif for decisive conference statements.
- Editorial italic serif for human emphasis, never as decoration.
- Monospace for dates, venues, stages, statuses, and scientific metadata.
- Voice is direct, factual, and confident. Unknown fees, deadlines, credit hours, addresses, and phone numbers are explicitly marked “to be announced”; none are invented.

## Motion

- One persistent R3F canvas for the full page.
- Five states: anatomical form, angular disassembly, free field, exact return, textured solid.
- Pointer proximity, drag orientation, and deliberate impulse remain available without blocking normal scrolling or links.
- Reduced-motion users receive the final authored solid immediately.
- Supporting UI uses restrained opacity/transform transitions only.

## Information architecture

1. Hero / event identity / date / registration status
2. About / verified scale
3. Programme / workshops
4. Technology capabilities
5. Scientific highlights
6. Faculty status / organising committee
7. Abstracts / awards
8. Industry participation
9. Venues / Hyderabad
10. Questions / pending information
11. Registration opening-soon CTA / secretariat

## Reference transformation

- Preserve the reference sites’ persistent-subject narrative, dense event information, and mobile-first section sequencing.
- Replace their generic gradient cards, fabricated counters, dark glass navigation, and full-screen video gates with an original white/red operative-field system.
- Keep the runtime code owned by this project; no copied visual assets or reference code.
